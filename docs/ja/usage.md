# タスクとワークスペース

## タスクを作成・検索する

**新しいタスク** または **⌘N / Ctrl+N** で新しい会話を始めます。目標を入力し、**Enter** で送信、**Shift+Enter** で改行します。フォルダー選択をキャンセルしても下書きは残ります。

**最近** の **タスク履歴** から履歴を表示し、タイトルやワークスペースで検索します。タスクを選ぶと会話と結果を確認できます。再起動後も履歴は残りますが、未完了のタスクは自動再開されません。

サイドバーは **プロジェクト → 最近** の順で表示し、会話を各プロジェクトの下にまとめます。プロジェクト名をクリックして展開・折りたたみ、右側の作成アイコンから会話を始めます。見出しの **+** で **プロジェクトを作成** を開き、名前とソースフォルダーを選んで作成します。フォルダー選択は仮の状態で、キャンセルしてもプロジェクトや現在のワークスペースは変わりません。ソースメニューではファイル選択と絶対パス入力も利用できます。ファイルの場合は親フォルダーを使用し、同じフォルダーの別名は一つにまとめます。同名の別フォルダーは親パスで区別します。

**… → サイドバーを整理** で **プロジェクト別に表示** と **まとめて表示** を切り替えます。まとめて表示では通常の会話を一つの一覧にし、ピン留めとカスタムセクションの所属は保持します。**会話の並び順** は **最近の更新** または **手動で並べ替え** です。ドラッグか **Alt + 上下キー** で並べ替えられ、表示方法と順序はこの端末に保存されます。新しい会話は先頭に表示します。まとめて表示の **タスク履歴** は一覧の下にあります。

プロジェクトを右クリックするか、フォーカスして **Shift+F10** を押すと、**ピン留め、編集、セクション、会話をアーカイブ、プロジェクトを削除** のメニューを開きます。ピン留めとセクションは再起動後も保存されます。アーカイブはそのプロジェクトの終了済み会話だけが対象で、実行中のタスクは先に完了またはキャンセルする必要があります。削除はサイドバーから非表示にするだけで、ファイルや会話履歴は残り、**タスク履歴** から確認できます。同じフォルダーやその中のファイルを再び追加すると、以前の会話と保存済みの名前が再び関連付けられます。**最近** の **新しい会話** はプロジェクトにアクセスしない通常の会話を作成します。別のプロジェクトに切り替えても、追加の質問は元のプロジェクトを使用します。

コンテキストメニューと編集画面のどちらからプロジェクトを削除する場合も確認が必要です。初期フォーカスは **キャンセル** で、ファイルや記録は削除されません。

会話を右クリックすると、名前変更、ピン留め、未読、セクション変更、分岐、共有、コピー、新しいウィンドウ、開くアプリ、アーカイブ、完全削除を利用できます。分岐は保存済みの会話内容を複製し、モデル呼び出しや実行再開は行いません。Git プロジェクトの会話は現在の作業ファイルを含む新しいワークツリーに分岐できます。既存の独立したワークツリーからは同じワークツリー内で会話を分岐できます。共有は Markdown のコピーまたはローカルへの書き出しで、アップロードや公開リンクの作成は行いません。完全削除には確認が必要です。独立したワークツリーがある場合は先にアーカイブしてください。

カスタムセクションはサイドバーの最上部に表示されます。見出しをクリックすると展開・折りたたみでき、状態はこの端末に保存されます。作成アイコンでセクション内に新しい会話を作成し、追加の質問や再試行でも所属が保持されます。検索中は該当する内容が一時的に展開されます。

カスタムセクションの **…** ボタンまたは右クリックメニューには **編集、すべて既読にする、会話をアーカイブ、新しいセクション、セクションを削除** があります。空のセクションも保存されます。セクションを削除するとプロジェクトと会話が既定の場所に戻り、ファイルと履歴は保持されます。アーカイブは配下のプロジェクトの会話も対象で、実行中のタスクは先に終了またはキャンセルする必要があります。

**プロジェクトの会話 → メモリーと拡張機能** はプロジェクトに関連付けた会話画面の入力欄の下から開きます。プロジェクト内の新規会話でも利用できます。高さは固定で、**メモリ、拡張機能、自動実行と連携** のタブがあります。全体の保守と更新は **設定 → データと更新** にあります。内容は内部でスクロールし、タブの切り替えでウィンドウの位置やサイズは変わりません。

## 計画と実行

送信前に入力欄の **タスクのオプション** を開き、モード、ターン数、Worktree を選びます。追加設定は **検証と予算** 内にあります。

| モード   | 用途                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| **計画** | プロジェクトを読み、問題を説明し、手順を提案します。ファイル変更やコマンド実行は行いません。 |
| **実行** | 変更を行い、許可されたツールを実行します。                                                   |

**最大ターン数** は 1 回のタスクでモデルを呼び出す回数の上限です。1〜100 を指定でき、初期値は 30 です。上限到達や同じ失敗の繰り返しで停止することがあります。

計画を確認したら **実行モードで計画を使用** をクリックし、準備された指示を必要に応じて編集して送信します。このボタンだけでは実行は始まりません。

## 一時停止・中止・続行

- **一時停止** は次の安全な区切りで止まります。実行中のツールが終了するまで待つ場合があります。
- **再開** は一時停止したタスクを続けます。
- **キャンセル** は現在のタスクを止めます。すでに適用された変更は自動で戻らないため、**変更** で確認してください。
- **再試行** は同じ依頼で新しい実行を始めます。先にエラーと現在のファイルを確認してください。
- 完了・失敗・中止したタスクは下部の追加質問欄で続けられます。追加質問欄の **タスクのオプション** で次のモードを選び、**前のターン** で以前の会話に戻れます。

## 操作を許可する

ツール名、引数、対象ワークスペースを確認してから **今回のみ許可**、**セッション中は許可**、**常に許可**、**拒否** を選びます。継続的な許可は信頼できる操作だけに与えてください。コマンドや外部ツールは自分のアカウントの権限でコンピューターを操作します。

## ファイルと変更を確認する

**ワークスペースツール → ファイル** で対象タスクのツリーを開きます。フォルダーは最初は折りたたまれています。クリックで開閉し、**1 階層展開** では依存・生成フォルダーを除くソースを段階的に開きます。**すべて折りたたむ** で全体を閉じ、ファイルをクリックすると読み取り専用で表示します。

タスクが一時停止状態になるか終了するのを待ってから、**変更** を操作します。

| 操作         | 結果                                                     |
| ------------ | -------------------------------------------------------- |
| **承認**     | 変更をレビュー済みにします。Git コミットは作成しません。 |
| **拒否**     | その変更前の状態に戻します。                             |
| **取り消す** | 承認済みを含め、変更を取り消します。                     |

ファイルに後から変更が加わった場合、上書きが拒否されることがあります。新しい変更を先に確認し、同じファイルへの複数の変更は逆順で取り消してください。デモのレビュー操作はサンプルデータだけに適用されます。

結果カードにはツールの操作とテスト結果が表示されます。Agent の回答だけでテスト成功と判断せず、実際の記録を確認してください。

## 独立した Worktree を使う

Git リポジトリで実行タスクを始める際、**Git ワークツリーで分離** を有効にすると、主ワークスペースと変更を分けられます。リポジトリには最初のコミットが必要です。**ワークツリーの開始状態** で最新コミット、または現在の未コミットファイルを含める方法を選びます。

追加質問も同じ Worktree を使います。完了後も Worktree は残ります。**受け渡しをプレビュー**、適用、アーカイブ、復元の操作は [実行・検証・再開](run-controls.md) を参照してください。

## ターミナルとブラウザー

**ターミナル** の **ターミナルを開く** で、選択したタスクのフォルダーにシェルを開きます。タスク未選択時は現在のワークスペースを使います。終了後は **ターミナルを再起動** で新しいセッションを開けます。入力したコマンドはコンピューター上で直接実行されます。

ブラウザーを使う場合は実際のモデルを接続し、ページを開く、調べる、スクリーンショットを撮るよう依頼します。権限リクエストを確認してください。画像がある場合、**ブラウザー** に現在のページのスクリーンショットが表示されます。デモはブラウザーを起動しません。

## 任意のアカウントと同期

**設定 → アカウントと同期** にサーバー URL、メールアドレス、パスワードを入力します。新規登録する場合は **アカウントを作成** を選び、サインインします。

- **選択したタスクをアップロード** は指示、選択ファイルの情報、ツール結果をサーバーに送ります。API キーは含みませんが、送信内容を事前に確認してください。
- **スナップショットをダウンロード** はリモートのタスク記録を取得します。ローカルのプロジェクトファイルを置き換えたり、タスクを再開したりしません。
- **ログアウト** はアカウントのセッションを終了します。

ローカルのタスクとデモにアカウントは不要です。接続先はサーバー管理者に確認してください。この手引きにはサーバーの構築手順は含みません。

検証、実行中の指示、再起動後の再開、予算、権限は [実行・検証・再開](run-controls.md) を参照してください。

同期スナップショットを **ローカルで続行** から新しい会話へ取り込めます。過去の結果は参考情報です。[実行と再開](run-controls.md) を参照してください。
