# プロバイダー API の監査

**2026-11-14** に公式ドキュメントを確認しました。現在の 17 個の名前付きバックエンドは公式またはローカル API を提供しており、API 全体を終了した根拠は見つかりませんでした。その理由で任意の削除はしていません。地域、アカウント、サブスクリプションや旧モデルの利用制限とは区別します。

一覧と公式リンクは[英語の監査記録](../provider-api-audit.md)にあります。設定画面にもプロバイダーの API ドキュメントへのボタンを追加しました。Custom compatible は手動エンドポイント、Demo はシミュレーションで接続プロバイダーの選択肢には含みません。

チャット契約の認証情報は開発者 API キーとは異なります。接続テストでは実際のツール呼び出しを確認し、モデル一覧は端末 API から取得します。ドキュメントの存在は特定の資格情報・地域・残高・モデルが動くことを保証しません。この監査では有料モデルを呼びませんでした。
