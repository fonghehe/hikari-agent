# モデル設定

## サービスへ接続

サイドバー下部の **モデル設定** でプロバイダーを選び、アカウントで利用できるモデル ID と必要な API キーを入力して接続します。会話や添付の分析にはワークスペースは不要です。開発タスクではワークスペースを開いてください。

OpenAI、Azure OpenAI / Foundry、Anthropic、Google Gemini、DeepSeek、Qwen、Kimi、GLM、Doubao、MiniMax、SiliconFlow、Groq、Grok、Mistral、OpenRouter、Ollama、LM Studio のプリセットを用意しています。他の Chat Completions サービスには **OpenAI compatible** を選びます。アカウントの地域やゲートウェイに合わせて接続先を変更できます。

サービスが指定する接続先を使ってください。Qwen にはワークスペース・地域固有の接続先もあります。Kimi のキーは地域間で共用できません。Doubao ではデプロイ ID が必要な場合があります。Azure は v1 API、API キーとデプロイ名を使用します。旧バージョンの API と Entra サインインはこのプリセットでは対応しません。Anthropic と Gemini はネイティブのプロトコル、その他は Chat Completions を使います。AWS 署名や Vertex OAuth などは互換ゲートウェイ経由で接続できます。

**利用可能なモデルを取得** で一覧を読み込み、モデル欄の候補から選ぶか手動入力します。一覧を取得できなくても手動で設定できます。一覧の全モデルがツールや画像に対応しているとは限りません。

## モデルの機能

- 開発タスクでは **このモデルはツール呼び出しに対応** を有効にします。無効なら通常の会話専用となり、ツール定義を送信しません。
- 画像対応モデルでのみ画像入力を有効にします。テキストモデルでもローカル OCR の文字を利用できます。
- 通常の応答のみ対応するサービスでは **ストリーミング応答** を無効にします。
- **コンテキストウィンドウ** と **最大出力トークン** をモデルの上限に合わせます。出力用の領域を確保します。
- **推論の強度** は既定値のままにするか、モデルが対応する値を選んでください。

接続テストは少量の課金対象リクエストを送り、ツール呼び出しが返るか確認します。開発品質全体を保証するものではありません。サービスのエラーをサンプル回答に置き換えません。

## 設定の保存と切り替え

**新しいモデル設定** を選び、任意の名前を入力して接続します。**保存済みモデル設定** から選び直して接続すると有効になります。新しい設定は新規タスクに適用されます。再開するタスクでは元の設定を使います。モデルや接続先が変わった場合は元に戻すか、再試行で新しいタスクを作成します。

OS の安全な保存機能が利用できればキーを暗号化します。利用できなければセッション中のみ保持します。キーを設定画面、会話のエクスポート、同期へ返しません。未完了のタスクが使用する設定を削除するには、タスクを完了またはキャンセルしてください。

## 任意の意味検索

**意味検索** を有効にして、別の **埋め込みモデル**、**接続先**、**API キー** を設定します。OpenAI Embeddings 互換の接続先が必要です。ローカルサービスでは空のキーが許可される場合があります。会話と埋め込みは別のサービスを選べます。

添付とプロジェクト記憶をキーワードと意味の両方で検索し、出典ラベルを保持します。テキストを送信する前に通信の承認が必要です。ベクトルはローカルに保存し、内容・モデル・接続先が変われば更新します。同じモデル ID の次元数を変更しないでください。

対象の文書集合とプロジェクト記憶を送信します。コードリポジトリ全体を自動で送ることはありません。最大 2,000 チャンク・300 万文字です。超える場合は分割するか意味検索を無効にします。埋め込み費用はチャット予算に含めません。無効でもローカルのキーワード検索を使用できます。有効にしたサービスのエラーは明示します。

## オフライン利用

オフラインデモではキーやワークスペースなしでサンプルを試せます。既存のデモ会話は継続や再試行でもシミュレーションです。Ollama や LM Studio に接続すれば実際のローカルモデルをオフラインで使用できます。機能は選択したモデルによって異なります。
