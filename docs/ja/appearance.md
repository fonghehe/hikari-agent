# 外観と言語

## テーマを選ぶ

サイドバー下部の **設定 → 外観と言語** を開き、**ライト**、**ダーク**、**システム** を選びます。システムはコンピューターの外観設定に従います。ファイルビューアー、変更パネル、ターミナルにも同じテーマが適用されます。

## 表示言語を選ぶ

同じパネルで **English**、**简体中文**、**日本語** を選びます。すぐに適用され、再起動後も保持されます。

言語設定は操作ボタン、ラベル、提案から入力される下書きに適用されます。会話、ファイル名、ツール出力の言語は変わりません。ドキュメントの言語メニューはデスクトップアプリの設定とは独立しています。

## ワークスペースを移動する

サイドバーにはカスタムセクション、ピン留め、プロジェクト、最近の会話を順に表示し、下部に **設定** メニューがあります。セクションの見出しで展開・折りたたみ、作成アイコンでそのセクション内に会話を作成できます。中央には会話を表示します。右パネルは既定で非表示です。上部の **ワークスペースツール** から **ファイル**、**変更**、**ターミナル**、**ブラウザー** を開きます。ブラウザーは必要時に表示し、**アカウントと同期** は設定から別のダイアログで開きます。パネルボタンで表示を切り替え、狭いウィンドウでは **Escape** で閉じられます。

各パネルは右端のスクロールバーで個別にスクロールできます。長いツール出力、ファイルビューアー、ターミナルは、その領域内でスクロールしてください。

## ダイアログの操作

モデル設定、外観、メモリーと拡張機能、タスクのオプション、添付プレビューは右上の **×** で閉じます。**Escape** や背景クリックでも閉じ、元の入口にフォーカスを戻します。外観とタスクのオプションは即時適用され、モデル設定は **モデルを接続** が必要です。閉じるだけではタスク実行や接続を始めません。

入力欄とドロップダウンの幅は、プロジェクト設定や同期ダイアログを含むアプリ全体で共通の規則を使います。数値はコンパクトに、名前・パス・接続先は用途に合う幅で表示します。関連する項目は余裕があれば横に並び、狭い画面では縦に配置されます。メモリーと拡張機能のウィンドウは高さを保ち、タブの内容が内部でスクロールします。

## キーボード操作

| キー                        | 操作                                         |
| --------------------------- | -------------------------------------------- |
| **⌘N / Ctrl+N**             | 新規タスクを作成し、入力欄に移動。           |
| **Enter**                   | 指示を送信。                                 |
| **Shift+Enter**             | 改行。                                       |
| **Escape**                  | ダイアログ、または狭い画面のツールを閉じる。 |
| ファイル内の **↑ / ↓**      | 表示中の項目を移動。                         |
| ファイル内の **→ / ←**      | 展開、折りたたみ、親フォルダーへ移動。       |
| ファイル内の **Home / End** | 最初・最後の項目へ移動。                     |
| ファイル内の **Enter**      | 選択したファイルを開く。                     |
