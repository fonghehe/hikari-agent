# 外観と言語

## テーマを選ぶ

サイドバー下部の **外観と言語** を開き、**ライト**、**ダーク**、**システム** を選びます。システムはコンピューターの外観設定に従います。ファイルビューアー、変更パネル、ターミナルにも同じテーマが適用されます。

## 表示言語を選ぶ

同じパネルで **English**、**简体中文**、**日本語** を選びます。すぐに適用され、再起動後も保持されます。

言語設定は操作ボタンやラベルに適用されます。会話、ファイル名、ツール出力の言語は変わりません。ドキュメントの言語メニューはデスクトップアプリの設定とは独立しています。

## ワークスペースを移動する

左側にワークスペースとタスク、中央に会話、右側に **ファイル**、**変更**、**ターミナル**、**ブラウザー**、**同期** が表示されます。右上のボタンでツールパネルを表示・非表示にできます。狭いウィンドウでは **Escape** でツールのドロワーを閉じられます。

各パネルは右端のスクロールバーで個別にスクロールできます。長いツール出力、ファイルビューアー、ターミナルは、その領域内でスクロールしてください。

## キーボード操作

| キー                        | 操作                                     |
| --------------------------- | ---------------------------------------- |
| **⌘N / Ctrl+N**             | 新規タスクを作成し、入力欄に移動。       |
| **Enter**                   | 指示を送信。                             |
| **Shift+Enter**             | 改行。                                   |
| **Escape**                  | 狭いウィンドウのツールドロワーを閉じる。 |
| ファイル内の **↑ / ↓**      | 表示中の項目を移動。                     |
| ファイル内の **→ / ←**      | 展開、折りたたみ、親フォルダーへ移動。   |
| ファイル内の **Home / End** | 最初・最後の項目へ移動。                 |
| ファイル内の **Enter**      | 選択したファイルを開く。                 |
