# デスクトップのパッケージ

標準パッケージは別の Chromium や、既に UI にバンドルしたワークスペース依存を重複して含めません。

```sh
pnpm desktop:pack
pnpm test:package
pnpm desktop:dist
```

Linux の実行ファイル名は煙テストの入口と同じ `hikari` に固定します。macOS/Linux のパッケージ煙テストは OS サンドボックス実行を確認します。ホスト型 Windows には Linux Docker エンジンとイメージがないため、ホストプロセス実行を確認します。Windows Docker サンドボックスの動作を証明するものではありません。

esbuild の外部インポートから `dist/runtime-dependencies.json` を作り、`stage-package.mjs` が必要な本番依存を `.artifacts/package/desktop` に配置します。対象 OS/CPU のネイティブ依存、ライセンス、OCR 資産を保持し、テスト、例、ソースマップ、デバッグ記号、他プラットフォームの PTY を除外します。

`package.mjs` は独立した本番アプリから electron-builder を呼び、pnpm の元ワークスペースから不要な依存が戻ることを防ぎます。asar を使い、ネイティブモジュールと OCR Worker の依存閉包だけを必要に応じて展開します。`dist/package-report.json` はステージ容量であり、インストーラー容量とは別です。

変更前の macOS arm64 ZIP は **434,708,395 バイト**、展開内容は **965,958,738 バイト**で、別のブラウザーが **327,140,136 バイト**でした。最終 ZIP/DMG を比較してください。Electron 本体の固定容量は残ります。

デスクトップのブラウザーは同じ Electron の独立プロセスを、使い捨てプロファイルと loopback CDP で利用します。`browser-worker.ts` はアプリ起動前に分岐し、アプリ IPC や DB を開きません。ページは Node を無効にし、隔離とサンドボックスを有効にします。終了時にプロセスと一時プロファイルを除去します。別の Chrome や Playwright のダウンロードキャッシュは不要です。CLI/サーバーのブラウザー環境は従来どおりです。

実パッケージの煙テストは空のブラウザーキャッシュで起動し、IPC、会話、PDF/DOCX/画像、オフライン OCR、PTY、制限付き実行、受け入れ検査とブラウザーを確認します。無資格情報のローカルフィクスチャだけを使用します。今回の実測は macOS arm64 に限り、他 OS はそれぞれの CI が必要です。ローカル署名は ad-hoc で、公証・公開は行いません。

## ローカル成果物の実測

2026-11-14 の macOS arm64 ZIP は **171,693,641 バイト**、DMG は **171,500,419 バイト**です。以前の ZIP（434,708,395 バイト）から **60.5% 削減**し、ZIP 内容の合計は 965,958,738 から 429,857,576 バイトになりました。オフライン OCR を保持し、別のブラウザーと重複する `node_modules/monaco-editor` を除外しています。ローカル ad-hoc 署名であり、公証・公開はしていません。
