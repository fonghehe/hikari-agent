# 困ったとき

## 回答がサンプルのように見える

**デモモード · オフライン** が有効か確認してください。デモは用意された回答とサンプルファイルを使います。自分のプロジェクトではモデルを接続し、ワークスペースを開いて新規タスクを始めます。デモ会話を続けてもデモのままです。

## モデルへのリクエストが失敗する

プロバイダー、Base URL、モデル ID、API キーを確認します。モデルが自分のアカウントで利用でき、サービスに接続できるか確認してください。利用上限のエラーではプロバイダーのアカウントを確認し、後で再試行します。失敗したリクエストはデモの回答に置き換わりません。

## タスクが待機中、または進まない

タイムラインに権限リクエストがないか確認し、許可または拒否します。一時停止したタスクには **再開** が必要です。同じワークスペースを別のタスクが使っている場合、終了を待つか、そのタスクを中止します。

ターン数の上限や失敗の繰り返しで停止した場合、結果を読み、依頼範囲を狭めて再試行または追加質問します。上限を増やすだけでは原因が解消しない場合があります。

## 再起動後にタスクが中断されている

履歴は残りますが、未完了タスクは自動再開されません。現在のファイルを確認し、**再試行** または追加質問で作業を続けてください。

## レビューできない、または元に戻せない

一時停止状態になるか、タスクの終了を待ちます。記録した変更の後にファイルが変わった場合、新しい変更を先に確認します。同じファイルの複数の変更は逆順に取り消してください。

## ファイルやターミナルのフォルダーが違う

選択中のタスクとワークスペースを確認してください。独立した Worktree のタスクはそのフォルダーを使います。**新しいタスク** で新しい会話に戻れます。デモのファイルはサンプルです。対話型ターミナルには実際のワークスペースが必要で、終了したターミナルは再起動します。

## ブラウザーでページを開けない

実際のモデルを接続し、ブラウザーのリクエストを許可してネットワークを確認します。ソースから使う場合は `pnpm exec playwright install chromium` でブラウザーをインストールしてください。デモはブラウザーを起動しません。

## 同期できない

サーバー URL、アカウント、接続を確認します。リビジョンの競合が出た場合、最新のスナップショットをダウンロードして確認し、再アップロードを判断します。ダウンロードはローカルファイルを上書きしません。同期を使わずにローカルの作業を続けられます。

## 表示やモデル設定が変わった

**外観と言語** で好みのテーマや言語を選び直します。接続できない場合は **モデル設定** を再入力してください。会話やツール出力は表示言語の変更では翻訳されません。

## 添付を送信できない

プレビューで形式とサイズを確認してください。スキャン PDF は画像を添付します。画像には **このモデルは画像に対応** と画像対応モデルが必要です。送信エラーでも下書きは残り、読み取りエラーでも有効な添付は保持します。[添付の制限](attachments.md) を確認してください。
