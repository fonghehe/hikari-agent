# はじめに

## モデルなしで試す

Hikari を開き、**デモモード · オフライン** を選んだまま使います。API キーやワークスペースは不要です。

1. `Hello`、`Analyze the sample architecture`、`Fix the sample tests` を入力します。
2. **Enter** または送信ボタンで送信します。**Shift+Enter** で改行できます。
3. 回答とタスクのタイムラインを確認します。提案カードは下書きを入力するだけなので、内容を確認してから送信してください。
4. タスクが終了したら、下部の追加質問欄で会話を続けます。

デモの回答は用意されたサンプルです。ファイル変更やチェックはサンプルデータだけに適用され、実際のプロジェクト変更やテスト実行は行いません。

## 質問と添付の分析

[モデルを接続](configuration.md) すると、ワークスペースなしで質問できます。クリップから添付するか、ファイルのドロップや画像の貼り付けを使います。[対応形式と画像設定](attachments.md) を確認してください。

## 自分のプロジェクトを使う

1. **ワークスペースを開く** をクリックし、プロジェクトのフォルダーを選びます。
2. サイドバー下部の **モデル設定** から[モデルを接続](configuration.md)します。
3. **新しいタスク** をクリックします。まず調査する場合は **計画**、変更する場合は **実行** を選びます。
4. 「カートのテスト失敗の原因を説明して修正して」など、具体的な目標を入力します。
5. 権限リクエストを確認し、操作を許可するか判断します。
6. **ファイル** で内容を読み、**変更** で差分を確認します。結果を受け入れる前に実際のチェック記録を確認してください。

**タスク** から過去の会話を探せます。**新しいタスク** は別の会話を始め、追加質問は選択中の会話を続けます。
