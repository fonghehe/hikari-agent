# ファイルと画像で質問する

## 添付する

入力欄のクリップ **ファイル・画像を添付** をクリックするか、ファイルを入力欄にドロップします。クリップボードのスクリーンショットも貼り付けられます。同じ質問に文書と画像を添付できます。

1. ファイルを追加し、**添付ファイルを準備中…** が消えるまで待ちます。
2. 添付をクリックして、実際に抽出したテキストや処理後の画像を確認します。不要な添付は **×** で削除します。
3. 「この要件を比較して」「画像のエラーを説明して」など、具体的な質問を入力します。
4. **Enter** または送信矢印で送信します。質問を空にすると、添付の要約を依頼します。

ワークスペースを開かずに質問できます。実際の分析にはモデルを接続してください。ローカルプロジェクトの確認や編集には、そのワークスペースを開き、新しいタスクを作成します。

## 形式と制限

| 種類                                                        | 送信する内容                                                                 |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------- |
| UTF-8 テキスト、Markdown、CSV、JSON、一般的なコードファイル | 読み取り可能なテキスト。                                                     |
| PDF                                                         | 最大 100 ページのテキストと、最大 20 ページのスキャンをローカル OCR で抽出。 |
| DOCX                                                        | 文書の本文。書式、埋め込み画像、コメントは含みません。                       |
| PNG、JPEG、WebP、GIF                                        | 1600 × 1600 ピクセル以内に縮小した画像。GIF は最初のフレームのみ。           |

添付は最大 **6 件**、画像は最大 **3 枚**、1 件 **10 MB**、合計 **20 MB** です。初期プレビューは文書ごとに **12,000 文字**、質問全体で **24,000 文字**を分配します。保存する全文は 1 件 **512,000 文字**まで検索・順次読み取りできます。**一部のみ** はプレビューの表示です。全文検索とページ・段落の引用を依頼してください。英語・中国語・日本語の OCR データを同梱し、端末内で認識します。読み取りにくい画像では誤認識する場合があります。

非対応、読み取り不能、上限超過のファイルにはエラーが表示されます。同時に追加した有効なファイルは残ります。表計算ファイル、圧縮ファイル、古い `.doc`、暗号化された文書は非対応です。必要な内容を CSV、UTF-8 テキスト、PDF、画像に変換してください。

## 画像とオフラインデモ

実際の画像分析には、画像入力に対応するモデルを選び、[モデル設定](configuration.md) で **このモデルは画像に対応** を有効にしてください。スイッチだけではテキスト専用モデルに画像理解を追加できません。文字を認識できた画像はテキスト専用モデルでも OCR 結果を分析できますが、レイアウトや視覚的な詳細は見えません。文字のない画像には画像対応モデルが必要です。最近の会話に画像が含まれる場合も、画像対応モデルが必要です。

オフラインデモはキーやネットワークなしで文書の抜粋と画像の名前、サイズを表示します。**画像の内容を理解したり、実際のモデルによる分析を行ったりはしません**。実際のモデルのエラーをデモ回答に置き換えることもありません。

## 続ける・結果を確認する

送信済みの添付はローカルの履歴に保存され、再起動後もプレビューできます。**再試行** は元の添付を使います。追加の質問では最近の会話の添付を参照できます。長い会話では、重要な資料を新しい質問に再添付してください。会話を切り替えても、現在のセッション中は未送信の下書きを保持します。**新しいタスク** は空の下書きで始まります。未送信の添付は一時キャッシュで、1 時間後や容量不足時に期限切れになる場合があります。未送信の下書きは再起動後には復元されません。

回答では見出し、リスト、コード、表が使えます。**コードをコピー** でコードブロックを、**回答をコピー** で回答全体をコピーします。外部リンクは既定のブラウザーで開きます。回答のリモート画像はリンクで表示し、自動では読み込みません。

## コンテンツの送信先

送信後、抽出したテキストと処理後の画像はローカルに保存されます。接続したモデルには質問の添付を送信し、追加の質問でも最近の添付を送る場合があります。そのサービスと共有したい資料だけを添付してください。デモは端末内で動作します。

任意のタスク同期では、添付の全文と画像プレビューを送信しません。ただし、指示、ファイル名、モデルの回答に機密情報が引用される場合があるため、アップロード前に確認してください。別の端末でスナップショットを取得しても添付ファイルは復元されません。
