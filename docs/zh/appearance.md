# 外观与语言

## 选择主题

在侧栏底部打开 **设置 → 外观与语言**，选择 **亮色**、**暗色** 或 **跟随系统**。跟随系统会随电脑的外观设置变化；文件查看器、改动面板和终端使用所选主题。

## 选择界面语言

在同一面板选择 **English**、**简体中文** 或 **日本語**。设置立即生效，重启后保留。

界面语言会改变控件、标签以及快捷建议填入的草稿，对话、文件名及工具输出保持原文。文档站的语言菜单独立于桌面应用的语言设置。

## 浏览工作区

左侧栏依次显示自定义分区、置顶、项目和最近对话，底部为 **设置** 菜单，中间显示对话。点击分区标题可展开或收起，右侧新建图标会在该分区内创建对话。右侧面板默认隐藏，通过顶部 **工作区工具** 选择 **文件**、**改动**、**终端** 或 **浏览器**；浏览器按需打开，**账户与同步** 从设置打开独立弹窗。面板按钮控制工具区域显隐，窄窗口下按 **Escape** 关闭工具抽屉。

各面板可独立滚动，滚动条位于各自右边缘。长工具输出、文件查看器和终端需在对应区域内滚动。

## 弹窗交互

模型设置、外观、记忆与扩展、任务选项和附件预览统一使用右上角 **×**；也可按 **Escape** 或点击遮罩关闭，关闭后焦点回到入口。外观与任务选项即时生效，模型配置需要点击 **连接模型**。关闭弹窗不会启动任务或连接模型。

全局输入框和下拉框共用尺寸规则，覆盖项目设置和同步弹窗等界面。数值字段保持紧凑，名称、路径和地址按用途分配宽度；空间足够时，关联字段并排显示，窄窗口中自动堆叠。记忆与扩展窗口保持固定高度，分页内容在内部滚动。

## 键盘快捷键

| 快捷键                  | 操作                                       |
| ----------------------- | ------------------------------------------ |
| **⌘N / Ctrl+N**         | 新建任务并聚焦输入框。                     |
| **Enter**               | 发送提示词。                               |
| **Shift+Enter**         | 换行。                                     |
| **Escape**              | 关闭当前弹窗；无弹窗时关闭窄窗口工具抽屉。 |
| 文件树内 **↑ / ↓**      | 在可见条目之间移动。                       |
| 文件树内 **→ / ←**      | 展开、折叠或返回父目录。                   |
| 文件树内 **Home / End** | 跳到首个或最后一个条目。                   |
| 文件树内 **Enter**      | 打开所选文件。                             |
