# 外观与语言

## 选择主题

在侧栏底部打开 **外观与语言**，选择 **亮色**、**暗色** 或 **跟随系统**。跟随系统会随电脑的外观设置变化；文件查看器、改动面板和终端使用所选主题。

## 选择界面语言

在同一面板选择 **English**、**简体中文** 或 **日本語**。设置立即生效，重启后保留。

界面语言只改变控件和标签，对话、文件名及工具输出保持原文。文档站的语言菜单独立于桌面应用的语言设置。

## 浏览工作区

左侧栏管理工作区与任务，中间显示对话，右侧展示 **文件**、**改动**、**终端**、**浏览器** 和 **同步**。右上角的面板按钮控制工具面板显隐；窄窗口下按 **Escape** 关闭工具抽屉。

各面板可独立滚动，滚动条位于各自右边缘。长工具输出、文件查看器和终端需在对应区域内滚动。

## 键盘快捷键

| 快捷键                  | 操作                     |
| ----------------------- | ------------------------ |
| **⌘N / Ctrl+N**         | 新建任务并聚焦输入框。   |
| **Enter**               | 发送提示词。             |
| **Shift+Enter**         | 换行。                   |
| **Escape**              | 关闭窄窗口工具抽屉。     |
| 文件树内 **↑ / ↓**      | 在可见条目之间移动。     |
| 文件树内 **→ / ←**      | 展开、折叠或返回父目录。 |
| 文件树内 **Home / End** | 跳到首个或最后一个条目。 |
| 文件树内 **Enter**      | 打开所选文件。           |
