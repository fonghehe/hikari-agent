# 快速开始

## 不连接模型也能体验

打开 Hikari，保留 **模拟模式 · 离线**，无需 API Key，也无需选择工作区。

1. 输入“你好”“分析示例项目”或“修复示例测试”。
2. 按 **Enter** 或点击发送箭头；**Shift+Enter** 换行。
3. 查看回答和任务时间线。示例卡片只填入草稿，确认内容后再发送。
4. 任务结束后，在底部的追问输入框继续对话。

模拟回答来自预设示例，文件修改和检查只影响示例数据，不会修改你的项目或执行真实测试。

## 问答与附件分析

[连接模型](configuration.md) 后，不打开工作区也可以提问。使用回形针添加文件、拖放文件或粘贴截图。[查看支持的格式和图片设置](attachments.md)。

## 使用自己的项目

1. 点击 **打开工作区**，选择项目目录。
2. 在侧栏底部打开 **模型设置**，[连接模型](configuration.md)。
3. 点击 **新建任务**。需要先分析时选择 **规划**；需要实施时选择 **执行**。
4. 描述明确的目标，例如“找到购物车测试失败的原因，解释问题并修复”。
5. 审阅权限请求，再决定是否允许操作。
6. 在 **文件** 面板阅读代码，在 **改动** 面板审阅修改；接受结果前查看实际检查记录。

点击 **任务** 查找历史对话。**新建任务** 开始独立对话；底部追问继续当前选中的对话。
