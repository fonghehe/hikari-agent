# 任务与工作区

## 新建和查找任务

点击 **新建任务** 或按 **⌘N / Ctrl+N** 开始新对话。输入目标后按 **Enter** 发送，**Shift+Enter** 换行。取消目录选择不会清空草稿。

点击 **最近** 标题旁的 **任务历史** 浏览历史，按任务标题或工作区搜索，再选择任务查看对话和结果。重启后历史仍可查看，未完成的任务不会自动继续执行。

侧边栏默认按 **项目 → 最近** 排列，项目对话嵌套在对应项目下。点击项目名称可展开或收起聊天，右侧的新建聊天图标用于在该项目中开始对话。标题旁的 **+** 打开 **创建项目**：输入名称、添加源文件夹，再点击 **创建项目**。选择目录时只暂存路径，取消不会添加或切换项目。源文件夹下拉菜单还支持选择文件和输入绝对路径；引入文件时，将其所在文件夹作为项目。同一目录及其路径别名会合并，避免重复项目。不同目录即使同名也会保持独立，并显示父路径以便区分。

标题旁的 **… → 整理侧边栏** 可选择 **分项目显示** 或 **合并显示**。合并显示将普通项目对话和独立聊天放在同一列表，置顶和自定义分区仍保持各自归属。**聊天排序方式** 提供 **最近更新** 和 **手动排序**；手动模式支持拖动，也可聚焦聊天后按 **Alt + 上/下方向键**。显示方式和手动顺序在本机保存，新聊天排在手动列表顶部。合并模式下，**任务历史** 位于聊天列表下方。

右键项目，或聚焦项目后按 **Shift+F10**，可打开 **置顶、编辑、分区、归档聊天、移除项目** 菜单。置顶和分区在重启后保留；归档聊天只影响该项目已结束的对话，须先完成或取消活动任务。移除只隐藏侧边栏中的项目及其对话，不删除文件和历史记录，仍可在 **任务历史** 中查看。再次引入相同文件夹或其中的文件，会自动关联原有对话并保留项目名称。**最近** 旁的 **新建对话** 创建不访问项目的普通对话；切换项目后，旧对话的追问仍使用原项目。

项目右键菜单和编辑窗口中的 **移除项目** 都需要确认，默认聚焦 **取消**；移除不会删除文件或记录。

右键侧栏对话，可重命名、置顶、标记未读、调整分区、分叉、分享、复制、在新窗口中打开、选择打开方式、归档或永久删除。分叉复制已保存的对话内容，不自动调用模型或恢复旧执行。Git 项目对话还可基于当前工作文件分叉到新工作树；已有独立工作树的对话可在原工作树内分叉。分享提供复制 Markdown 和本地导出，不会自动上传或生成公开链接。永久删除需要确认；有关联独立工作树的任务须先归档工作树。

自定义分区位于侧栏最上方，排在置顶、项目和最近之前。点击分区标题可展开或收起，收起状态会在本机保存；右侧的新建对话图标会在该分区中创建对话，新建、追问和重试均保留分区归属。搜索时会临时展开匹配的内容。

自定义分区标题旁的 **…** 或右键菜单提供 **编辑、全部标为已读、归档聊天、新建分区、移除分区**。空分区会保留。移除分区会把项目和对话放回默认位置，保留文件及历史记录。分区归档包括项目下的聊天，须先完成或取消活动任务。

**项目聊天 → 记忆与扩展** 入口位于关联项目的对话界面输入框下方，新建项目对话时也可使用，打开该项目的固定高度窗口，按 **记忆、扩展、自动化与集成** 分页。全局维护与更新位于 **设置 → 数据与更新**。内容在窗口内滚动，切换标签时窗口位置和尺寸保持不变。

## 计划与执行

发送前在输入框工具栏打开 **任务选项**，设置模式、最大轮次与工作树；验收、预算等高级设置在折叠区内：

| 模式     | 适用场景                                               |
| -------- | ------------------------------------------------------ |
| **规划** | 阅读项目、解释问题和提出步骤，不修改文件、不运行命令。 |
| **执行** | 实施修改并运行已批准的工具。                           |

**最大轮次** 控制一次任务的模型调用轮数，可设为 1–100，默认 30。任务可能在达到上限或反复遇到相同失败后停止。

审阅计划后，点击 **在执行模式中使用计划**，按需编辑准备好的提示词并发送。按钮只准备下一轮任务，不会直接开始执行。

## 暂停、取消与继续

- **暂停** 会在下一处安全边界停止。已经运行的工具可能先结束，任务才进入暂停状态。
- **继续** 恢复暂停的任务。
- **取消** 停止本轮任务；已完成的修改不会自动撤销，请在 **改动** 面板审阅。
- **重试** 使用相同请求开始新一轮。先阅读失败原因并检查当前文件。
- 任务完成、失败或取消后，可在底部追问。通过追问输入框旁的 **任务选项** 选择下一轮模式，通过 **上一轮** 返回先前对话。

## 审批操作

阅读工具名称、参数和目标工作区，再选择 **允许一次**、**本次会话允许**、**始终允许** 或 **拒绝**。只对可信操作授予长期权限。命令和外部工具会使用你的账户权限操作电脑。

## 阅读文件与审阅修改

通过 **工作区工具 → 文件** 打开所选任务的目录树，目录默认全部收起。点击目录展开或折叠；**展开一层** 逐层打开源码目录，跳过依赖与构建产物目录；**折叠全部** 收起整棵树。点击文件可在只读查看器中阅读。

先暂停并等待任务进入暂停状态，或等待任务结束，再操作 **改动** 面板：

| 操作     | 结果                                    |
| -------- | --------------------------------------- |
| **接受** | 将修改标记为已审阅，不会创建 Git 提交。 |
| **拒绝** | 恢复该修改之前的状态。                  |
| **撤销** | 撤回修改，包括已经接受的修改。          |

如果文件已发生后续变化，Hikari 可能拒绝覆盖。先审阅较新的修改；同一文件的多次修改需按相反顺序撤销。模拟模式的审阅操作只影响示例数据。

结果卡片记录工具操作和测试结果。Agent 的文字答复不代表测试通过，应查看实际记录。

## 使用独立 Worktree

在 Git 仓库中执行任务时，可勾选 **使用独立 Git 工作树**，将任务修改与主工作区分开。仓库需已有首次提交。通过 **工作树起始状态** 选择最新提交，或包含主工作区当前未提交的文件。

追问使用同一个工作树，任务完成后工作树仍保留。使用 **预览交付**、**应用到工作区**、**归档并清理工作树** 和 **恢复工作树** 管理结果，详见 [运行与恢复](run-controls.md)。

## 终端与浏览器

在 **终端** 面板点击 **打开终端**，即可在所选任务目录启动 shell；未选任务时使用当前工作区。终端退出后点击 **重启终端** 打开新会话。手动输入的命令会直接在电脑上运行。

需要浏览器操作时，连接真实模型，要求 Agent 打开页面、检查页面或截图，并审阅相关权限请求。有截图时，**浏览器** 面板显示当前页面的截图。模拟模式不会启动浏览器。

## 可选的账户与同步

在 **设置 → 账户与同步** 中填写服务器地址、邮箱和密码。需要注册时勾选 **创建账户**，然后登录。

- **上传选中任务** 会将任务提示词、所选文件上下文和工具结果发送到服务器，不包含 API Key。上传前请审阅内容。
- **下载快照** 获取远端任务记录供查看，不覆盖本地项目文件。通过 **在本地继续** 导入参考对话后可开始新的追问；不会恢复远端执行状态。
- **退出登录** 结束账户会话。

本地任务和模拟问答无需账户。服务器地址请向管理员获取；本手册不包含服务器部署教程。

验收、执行中补充要求、重启恢复、预算和命令权限详见 [执行、验收与恢复](run-controls.md)。

同步快照可通过 **在本地继续** 导入新对话，先前结果仅供参考。详情见 [运行与恢复](run-controls.md)。
