# 使用文件和图片提问

## 添加附件

点击输入框旁的回形针 **添加文件或图片**，把文件拖入输入区域，或直接粘贴剪贴板中的截图。同一个问题可以同时包含文档和图片。

1. 添加文件，等待 **正在处理附件…** 结束。
2. 点击附件预览实际提取的文本或处理后的图片；点击 **×** 移除不需要的附件。
3. 描述具体问题，例如“比较这两份需求”或“解释截图中的报错”。
4. 按 **Enter** 或点击发送箭头。只发附件、不写问题时，Hikari 会请求概括附件内容。

不打开工作区也能进行附件问答。连接模型后可获得真实分析；需要 Agent 阅读或修改本地项目时，打开项目工作区并新建任务。

## 支持的格式和限制

| 类型                                           | 发送的内容                                                     |
| ---------------------------------------------- | -------------------------------------------------------------- |
| UTF-8 文本、Markdown、CSV、JSON 和常见代码文件 | 文件中的可读文本。                                             |
| PDF                                            | 最多 100 页文本；其中最多 20 个扫描页面可本地 OCR。            |
| DOCX                                           | 提取的正文，不包含格式、内嵌图片和批注。                       |
| PNG、JPEG、WebP、GIF                           | 缩放至 1600 × 1600 像素以内，并提取 OCR 文本；GIF 使用第一帧。 |

每次最多 **6 个文件**，其中最多 **3 张图片**。原文件必须非空，单个最多 **10 MB**，合计最多 **20 MB**。模型初始预览每份最多 **12,000 字符**，每个问题合计最多 **24,000 字符**，由附件共同分配。每份完整提取文本最多 **512,000 字符**，可供全文搜索和顺序读取。**已截断** 仅指初始预览，不表示已保存的全文丢失。可要求 Agent 检索完整文档，并引用页码或段落标签。OCR 使用随应用打包的中日英识别数据，在本地运行；模糊扫描的识别结果可能有误。

不支持、无法读取或超限的文件会显示错误；同批次的有效文件仍然保留。暂不支持电子表格、压缩包、旧 `.doc` 和加密文档，可把相关内容导出为 CSV、UTF-8 文本、PDF 或截图。

## 图片与离线模拟

真实图片问答需要支持图片输入的模型，并在 [模型设置](configuration.md) 中开启 **此模型支持图片输入**。该开关不能让纯文本模型获得识图能力。纯文本模型可以基于成功识别的 OCR 文本回答，但看不到布局和图像细节。没有识别到文字的图片仍需视觉模型。近期对话中的图片也需要支持图片的模型。

离线模拟无需密钥或网络，可以展示文档摘录，并显示图片名称、尺寸；**不会理解图片内容，也不提供真实模型分析**。真实模型请求失败时会显示错误，不会替换成模拟回答。

## 追问和查看结果

已发送的附件保存在本地任务历史中，重启后仍可预览。**重试** 会携带原附件；追问可以引用近期对话中的附件。对话较长时，可在新问题中重新添加重要资料。切换会话会保留当前运行期间的未发送草稿；**新建任务** 开始空白草稿。未发送附件属于临时缓存，可能在一小时后或缓存不足时过期；未发送草稿不会在重启后恢复。

回答支持标题、列表、代码块和表格。使用 **复制代码** 复制单个代码块，或 **复制回答** 复制完整内容。外部链接会在默认浏览器打开；回答中的远程图片显示为链接，不会自动加载。

## 内容会发送到哪里

发送后，提取文本和处理后的图片保存在本地。已连接模型会收到当前问题的附件，追问时也可能收到近期附件；请只添加愿意提供给该服务的资料。离线模拟只在本机运行。

可选任务同步不上传完整附件内容或图片预览，但任务提示词、文件名和模型回答可能引用敏感内容，请先审阅再上传。其他设备下载的快照不会恢复附件文件。
