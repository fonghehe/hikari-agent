# 常见问题

## 回答像固定示例

检查是否启用了 **模拟模式 · 离线**。模拟模式使用预设回答和示例文件。需要处理自己的项目时，连接模型、打开工作区并新建任务；继续模拟对话仍会保持模拟模式。

## 模型请求失败

检查服务商、Base URL、模型 ID 和 API Key。确认模型对账户可用、服务可连接。遇到额度或限流提示时，检查服务商账户并稍后重试。Hikari 不会将失败请求替换为模拟回答。

## 任务等待或无法继续

检查时间线是否有权限请求，选择允许或拒绝后继续。暂停任务需点击 **继续**。同一工作区被其他任务占用时也可能等待，可等待其结束或取消。

达到模型轮次上限或反复失败时，先阅读结果、缩小任务范围，再重试或追问。单纯增加轮次不一定解决实际问题。

## 重启后任务中断

历史仍可查看，未完成任务不会自动继续。审阅当前文件后，通过 **重试** 或追问有意地继续工作。

## 无法审阅改动或撤销失败

先暂停并等待任务进入暂停状态，或等待任务结束。文件在记录修改后又发生变化时，先审阅较新的变化。同一文件的多次修改需按相反顺序撤销。

## 文件或终端目录不对

检查所选任务及其工作区。独立工作树任务使用自己的目录；点击 **新建任务** 返回新对话。模拟文件是示例数据。交互终端需要真实工作区，已退出的终端需重启。

## 浏览器无法打开页面

连接真实模型，批准浏览器请求并检查网络。从源码运行时，使用 `pnpm exec playwright install chromium` 安装浏览器。模拟模式不启动浏览器。

## 同步失败

检查服务器地址、账户和网络。出现版本冲突时，下载最新快照并审阅，再决定是否上传。下载不会覆盖本地项目文件；没有同步也可继续本地任务。

## 界面或模型设置变化

打开 **外观与语言** 恢复主题或语言。模型连接不可用时，在 **模型设置** 中重新填写。界面语言不会翻译已有对话和工具输出。

## 附件无法发送

预览附件并检查格式和大小。扫描版 PDF 请改用页面截图；图片需要开启 **此模型支持图片输入** 并选择支持图片的模型。发送失败会保留草稿；解析失败不会移除同批次的有效附件。[查看附件限制](attachments.md)。
