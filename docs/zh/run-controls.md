# 执行、验收与恢复

## 设置完成条件

展开输入框下的 **验收与预算**。添加 **文件验收**（路径、是否必须存在、可选的必需文本）或 **测试命令**（可执行程序、每行一个参数、工作目录）。测试命令仍需审批，请使用可信命令。

配置的条件未通过时，执行任务不能标记为完成。默认情况下，修改文件后必须在最后一次改动之后通过测试。对于文档修改等不适用测试的任务，选择 **仅使用验收条件**。规划模式只提出方案，不执行验收命令。

查看 **验收通过／未通过** 和实际测试记录。通过这些条件只能证明所检查的行为，不能保证所有代码都正确。

## 执行中补充要求

任务执行时可以继续输入文字并发送。补充要求在下一个安全的模型步骤应用；已经运行的工具可能先执行完。附件请在当前轮结束后发送。

Agent 提问时，可选择建议答案或输入自己的回答。任务会等待你的回答；等待期间仍可取消。

## 重启应用后恢复

有有效保存状态的未完成真实任务会显示 **已中断**。连接真实模型，选择任务并点击 **继续**。原任务的对话、工具结果、计划、待回答的问题和预算会继续使用，已完成操作不会自动重放。

操作在结果记录之前中断时，Hikari 会询问是否先检查实际结果再继续。重复操作前应检查文件或外部服务，因为操作可能已经生效。保存状态缺失或损坏时需使用重试。取消不会撤销已完成改动。

## 限制用量

发送前设置 Token、美元费用或时长上限；留空表示不增加该限制。恢复沿用原预算，不会重新计算额度。时长包含等待回答和审批的时间。

使用费用上限时，在 **模型设置 → 用量与兼容性** 输入服务的输入、输出单价。费用根据配置计算，不是实际账单。接口返回的用量显示 **接口返回**，接口不提供用量时显示 **估算**。兼容服务的输出限制参数和流式用量开关可以调整。**测试连接** 会消耗少量 Token，并检查接口能否返回工具调用。

## 选择命令权限

Agent 命令和 stdio MCP 默认使用 **系统沙箱**。允许修改工作区，限制读取工作区及运行时必要路径之外的私有文件；默认禁止联网，勾选 **允许沙箱联网** 后才放行。浏览器和 HTTP MCP 访问仍需审批。

macOS 使用原生沙箱，Linux 需安装 bubblewrap。Windows 需安装 Docker Desktop，并在项目根目录执行一次：`docker build -t hikari-sandbox:local -f containers/sandbox.Dockerfile .`。命令运行在 Linux 容器中；额外工具链可在派生镜像中安装，并使用相同标签。沙箱不可用时会报错，不会自动降级为主机权限。

只有需要沙箱无法提供的工具链时才选择 **主机权限**。批准的主机命令具有你的账户权限；交互式终端也直接运行在本机。

## 记忆、网页与更新

可要求 Agent 保存有用的项目事实或决策。在 **记忆与扩展** 查看或删除过时条目。项目记忆是本地参考资料，不能覆盖你的要求。

普通对话中也可审批读取网页。搜索需在模型设置中填写启用了 JSON 输出的 SearXNG `/search` 服务地址；查询会发送到该服务，再通过浏览器读取原始网页。服务未配置或出错时会明确报告，不会编造搜索结果。

**记忆与扩展 → 应用更新** 分别提供检查、下载和重启安装。更新需要带更新源的打包版本；安装前先结束活动任务。本地构建没有更新源时会明确提示。

## 开发工作流

在 **验收与预算 → 工作流** 选择 **调查 → 规划 → 实施 → 审查**。调查与规划只能读取项目，不能修改或执行命令。实施角色接收交接内容，用批准的工具完成修改并满足验收条件，再交给独立的只读审查角色检查。审查发现问题会回到实施，最多进行三轮返工。

工作流阶段、交接内容、任务摘要和待回答问题会随任务保存。**继续** 保留阶段和预算。审查角色无法使用写入、命令、浏览器或外部 MCP 工具。审查结论是模型判断，仍需查看实际测试证据。

## 工作树回写

新建执行任务时开启独立工作树。起始状态选 **HEAD** 获取已提交文件，或 **包含当前未提交文件** 复制已跟踪及未被 Git 忽略的未跟踪文件，原工作区文件不动。不会复制依赖与忽略文件，所需安装或初始化可作为需要批准的任务命令。仓库至少需要一次提交。

使用同一工作树的任务结束后，打开 **独立工作树 → 预览回写**，查看补丁与冲突，再点击 **回写工作区**。预览后的源文件或工作树变化会阻止回写，已有修改也不会被覆盖。一次最多支持 20 个 UTF-8 文本文件，每个 512 KB。更多文件、二进制、特殊权限或冲突请使用 Git 或外部编辑器。回写后在原工作区重新验证。**撤销回写改动** 不会覆盖之后的修改。

**归档并清理工作树** 会先在本地保存已跟踪和未跟踪文件，再移除工作树，不包含忽略文件。中断任务需先取消。**恢复工作树** 可以恢复保存的文件供查看或新一轮任务使用，不恢复旧授权和未完成运行。

## 整理对话

通过 **管理任务** 重命名、导出、归档或删除任务。历史页开启 **显示已归档任务** 可查看归档内容。**导入对话** 选择 Hikari JSON 文件；同步快照的 **在本地继续** 会创建本地新对话。如下一轮需要项目工具，先选择本地工作区。

导入只携带提问与先前回答作为参考，不恢复附件、断点、授权或验收结果。需要的文件请重新附加，并先检查当前工作区。导出不包含密钥、图片内容或私有运行断点。删除任务不会删除项目文件，需要先归档关联工作树。侧栏的 **最近工作区** 可重新打开以前选择的项目。

## 记忆和权限

在 **记忆与扩展** 编辑记忆标题、内容、来源、过期时间或删除。过期记忆仍可查看，但不参与检索。长任务可以维护包含目标、约束、决策、待办与证据的结构化摘要。

**持久权限** 展示保存的审批，**撤销授权** 会删除该审批并清空会话授权。已经运行的操作可能仍会完成，后续请求重新审批。
