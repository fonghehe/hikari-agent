# Getting started

## Try Hikari without a model

Open Hikari and leave **Demo mode · offline** enabled. You do not need an API key or a workspace.

1. Type `Hello`, `Analyze the sample architecture`, or `Fix the sample tests`.
2. Press **Enter** or click the send arrow. Use **Shift+Enter** for a new line.
3. Read the answer and task timeline. Suggestion cards fill your draft; send it when ready.
4. When the task ends, use **Follow-up prompt** to continue the conversation.

Demo answers use predefined examples. File changes and checks affect sample data only. They do not modify your project or run real tests.

## Ask a question or analyze an attachment

[Connect a model](configuration.md) and send a question without opening a workspace. Use the paperclip, drag files into the input, or paste a screenshot. [See supported files and image settings](attachments.md).

## Work with your own project

1. Click **Open workspace** and choose your project folder.
2. Open **Model settings** at the bottom of the sidebar and [connect a model](configuration.md).
3. Click **New task**. Choose **Plan** to explore first, or **Execute** to make changes.
4. Describe a focused goal, such as “Find the failing checkout test, explain the cause, and fix it.”
5. Review permission requests before approving operations.
6. Use **Files** to read files and **Diff** to review changes. Check the recorded test results before accepting the outcome.

Use **Tasks** to find previous conversations. **New task** starts a separate conversation; **Follow-up prompt** continues the selected one.
