# Appearance and language

## Choose a theme

Open **Settings → Appearance & language** at the bottom of the sidebar. Select **Light**, **Dark**, or **System**. **System** follows your computer's appearance setting. The file viewer, Diff and terminal use the selected theme.

## Choose an interface language

In the same panel, choose **English**, **简体中文**, or **日本語**. Changes take effect immediately and remain after restarting Hikari.

The interface language changes controls, labels and the draft inserted by quick suggestions. Conversations, filenames and tool output keep their original language. The documentation site's language menu is independent of the desktop setting.

## Navigate the workspace

Custom sections appear first in the sidebar, followed by pinned items, projects and recent chats. Section headings expand or collapse their content, and the compose icon starts a conversation in that section. The **Settings** menu stays at the bottom. The center shows the conversation. The right panel starts hidden; open **Workspace tools** at the top to select **Files**, **Diff**, **Terminal** or **Browser**. Browser is available on demand, and **Account & sync** opens a separate dialog from Settings. The panel button shows or hides the tools; **Escape** closes the narrow-window drawer.

Scroll each panel independently with its scrollbar at the right edge. Scroll inside a long tool output, file viewer or terminal to read that area.

## Dialog behavior

Model settings, appearance, memory and extensions, task options and attachment previews use the same top-right **×**. Click it, press **Escape**, or click the backdrop to close. Focus returns to the opener. Appearance and task options apply immediately; model settings require **Connect model**. Closing a dialog does not start a task or connect a model.

Native input fields and dropdowns share sizing rules throughout the app, including project settings and the sync dialog. Numeric fields stay compact; names, paths and addresses use appropriate widths. Related fields share a row when space allows and stack in narrow windows. The memory and extensions window keeps its height while tab content scrolls internally.

## Keyboard shortcuts

| Shortcut                | Action                                                     |
| ----------------------- | ---------------------------------------------------------- |
| **⌘N / Ctrl+N**         | Start a new task and focus the prompt.                     |
| **Enter**               | Send a prompt.                                             |
| **Shift+Enter**         | Insert a new line.                                         |
| **Escape**              | Close the active dialog, or the narrow-window tool drawer. |
| **↑ / ↓** in Files      | Move between visible entries.                              |
| **→ / ←** in Files      | Expand, collapse or move to a parent folder.               |
| **Home / End** in Files | Move to the first or last entry.                           |
| **Enter** in Files      | Open the selected file.                                    |
