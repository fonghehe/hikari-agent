# Appearance and language

## Choose a theme

Open **Appearance & language** at the bottom of the sidebar. Select **Light**, **Dark**, or **System**. **System** follows your computer's appearance setting. The file viewer, Diff and terminal use the selected theme.

## Choose an interface language

In the same panel, choose **English**, **简体中文**, or **日本語**. Changes take effect immediately and remain after restarting Hikari.

The interface language changes controls and labels. Conversations, filenames and tool output keep their original language. The documentation site's language menu is independent of the desktop setting.

## Navigate the workspace

The left sidebar contains your workspace and tasks; the center shows the conversation; the right panel contains **Files**, **Diff**, **Terminal**, **Browser** and **Sync**. Use the top-right panel button to show or hide the tools. In a narrow window, press **Escape** to close the tool drawer.

Scroll each panel independently with its scrollbar at the right edge. Scroll inside a long tool output, file viewer or terminal to read that area.

## Keyboard shortcuts

| Shortcut                | Action                                       |
| ----------------------- | -------------------------------------------- |
| **⌘N / Ctrl+N**         | Start a new task and focus the prompt.       |
| **Enter**               | Send a prompt.                               |
| **Shift+Enter**         | Insert a new line.                           |
| **Escape**              | Close the narrow-window tool drawer.         |
| **↑ / ↓** in Files      | Move between visible entries.                |
| **→ / ←** in Files      | Expand, collapse or move to a parent folder. |
| **Home / End** in Files | Move to the first or last entry.             |
| **Enter** in Files      | Open the selected file.                      |
